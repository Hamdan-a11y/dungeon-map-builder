# Dungeon Map Builder 🎲🗺️

A tabletop RPG dungeon map builder for Game Masters to design tile grid maps, export them as JSON, and share read-only views with players.

## Tech Stack

- **Frontend:** React (Vite), HTML5 Canvas
- **Backend:** Node.js, Express
- **Data Format:** JSON map representations

## Getting Started

### Backend (Server)

```bash
cd server
npm install
npm start
```
